# Systme de detection de lumiere
Ce projet est réalisé dans le cadre du module Communication Sans Fil en Licence 1 à l’Université
Nice Sophia Antipolis
# Description du projet

Ce projet à pour but de garder une pièce toujours éclairée en faisant sonné un buzzer et en envoyant un mail quand le niveau de lumière est en dessous du seuil fixé

# Materiel utilisé
Carte UCA
Buzzer
